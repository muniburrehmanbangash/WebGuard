# Changelog

## WebGuard 3.0 — current

- Produces one user-friendly HTML report per scan.
- Includes a browser option to print or save the report as PDF.
- Presents findings, evidence, and recommended actions in one place.
- Uses sequential filenames to avoid overwriting earlier reports.

## WebGuard 2.1 — archived

- Added styled HTML reports alongside JSON output.
- Included summary information, header observations, cookie observations, and technical evidence.

## WebGuard 1 — archived

- Initial scanner for selected HTTP security headers and cookie settings, with structured findings.
